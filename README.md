## 📌 About This Repository

This repository is an in-depth, hands-on reference guide designed to master modern JavaScript from foundational syntax to advanced runtime concepts. Built to document practical programming exercises, each module contains clear architectural notes alongside runnable code examples showcasing standard ECMAScript (ES6+) patterns and clean code principles.

---

### 📂 What This Repository Covers

* **Core Language Syntax & Primitives:**
  * Variable lifecycle and scoping rules (`var` vs. `let` vs. `const`).
  * Primitive and non-primitive data types, type coercion, and strict comparisons (`===` vs. `==`).
  * Arithmetic, logical, and assignment operator behaviors.

* **Control Structures & Iteration:**
  * Decision-making workflows using `if...else` chains and multi-condition `switch` blocks.
  * Deterministic and non-deterministic loops: standard `for`, `while`, and `do...while`.
  * Object and array iteration mechanics using `for...in` and `for...of`.

* **Function Architectures:**
  * Function declarations, function expressions, and ES6 arrow functions with lexical `this`.
  * Specialized function execution models: Immediately Invoked Function Expressions (IIFE), Higher-Order Functions (HOFs), and recursion.

* **Data Structures & Processing Pipelines:**
  * In-memory array operations (`push`, `pop`, `shift`, `unshift`) and functional transformations using `.map()`, `.filter()`, and `.reduce()`.
  * Object modeling: property management, nested data structures, method binding, and built-in helpers (`Object.keys()`, `Object.values()`, `Object.entries()`).

* **Browser Runtime & Interactivity:**
  * Document Object Model (DOM) traversal, structural node querying, dynamic styling, and runtime node creation.
  * Standard event handling patterns, DOM event listening, and user interaction management.

* **Asynchronous Programming & Concurrency:**
  * Moving beyond callback structures to resolve non-blocking operations.
  * Promise state management (`pending`, `fulfilled`, `rejected`) and promise chaining.
  * Modern asynchronous handling with `async` / `await` and resilient error management using `try...catch`.

* **Memory Scope & Closures:**
  * Lexical scoping environments and execution context lifecycles.
  * Practical closures for data encapsulation, private variable creation, and stateful function factory patterns.

---

### 🎯 Purpose of This Project

* **Foundational Rigor:** Bridge the gap between theoretical syntax and runnable code.
* **Modern Best Practices:** Emphasize ES6+ standards, deterministic variable handling, and clean code formatting.
* **Code Showcase:** Provide a structured, well-documented repository for technical review, onboarding, and developer portfolio evaluation.
